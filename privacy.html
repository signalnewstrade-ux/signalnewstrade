Privacy Policy

Signal News Trade — Last updated 2026-05-16

1. Who this policy applies to

Signal News Trade ("the App") is a personal automation tool operated by and for a single account owner. The App publishes original financial educational short videos to the operator's own social media accounts, including TikTok. This policy describes what data the App accesses, how it is stored, and how the operator can revoke access.

2. Data accessed from TikTok

The App requests the following TikTok OAuth 2.0 scopes:

  • user.info.basic — to read the operator's open_id, union_id, display_name, and avatar_url. Used to confirm the post lands on the correct account and to construct the canonical post URL.
  • video.upload — to transfer prepared MP4 files to TikTok's Content Posting API CDN.
  • video.publish — to publish the uploaded video to the operator's own TikTok profile.

The App does not request, read, or store any data belonging to any TikTok user other than the operator. It does not read public videos, comments, follower lists, messages, or analytics of other accounts.

3. Tokens and where they are stored

  • The OAuth access_token and refresh_token are stored exclusively on the operator's local machine in a .env file inside the project directory.
  • Tokens are never transmitted to any third-party server, analytics service, or cloud storage.
  • Tokens are read into memory only when the upload script runs, and the script communicates exclusively with TikTok's official API endpoints at open.tiktokapis.com.

4. Video content uploaded

All video files uploaded by the App are produced by the operator's own content pipeline: vertical 1080×1920 MP4 files containing original Spanish voice-over commentary on the day's financial market news. No content belonging to other TikTok users is republished by the App.

5. Data retention

  • Tokens persist locally until the operator deletes them or revokes API access from TikTok's app-management page.
  • Videos uploaded via the App follow TikTok's own retention and visibility policies once published.
  • Operational logs (status codes, publish_ids) are written locally and rotated by the operator manually.

6. Third-party sharing

No data accessed via the TikTok API is shared with any third party. The App does not integrate with analytics platforms, advertising networks, or external storage providers.

7. Operator rights and revocation

The account owner may revoke the App's access at any time via TikTok at:
https://www.tiktok.com/setting/manage-app

Revocation invalidates the stored tokens and prevents any further API access.

8. Security

  • The local machine running the App is protected by the operator's own operating system security controls (login password, disk encryption).
  • The .env file is excluded from version control via .gitignore and is never committed to public repositories.
  • The App uses HTTPS exclusively for all communication with TikTok APIs.

9. Children's data

The App is operated by an adult content creator and does not target, collect from, or process data belonging to minors. The operator certifies their own TikTok account is set to an audience of 18+.

10. Changes to this policy

Material changes to this policy will be reflected by updating the "Last updated" date at the top. Continued use of the App after a change constitutes acceptance.

11. Contact

Questions about this policy can be sent to contact@signalnewstrade.example.
