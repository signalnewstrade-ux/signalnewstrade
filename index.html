Signal News Trade

Automated financial education shorts for the Spanish-speaking trading community.

What it does

Signal News Trade is a personal content automation tool that publishes daily 60-second educational videos about financial markets to the operator's own social accounts (TikTok, YouTube Shorts, Instagram Reels, Facebook Reels). Each video summarizes the day's market-moving news for selected instruments (stocks, ETFs, crypto, FX, treasuries) with original Spanish voice-over.

How the TikTok integration works

  1. The operator authenticates once via TikTok OAuth 2.0 (Login Kit) and grants the scopes user.info.basic, video.upload, and video.publish.
  2. A backend pipeline generates a vertical 1080×1920 MP4 with voice-over and on-screen text from the day's financial news.
  3. The MP4 is uploaded to TikTok via the Content Posting API (/v2/post/publish/video/init/) using chunked PUT transfer.
  4. The uploader polls the status endpoint until PUBLISH_COMPLETE, then logs the resulting post identifier for the operator's records.

Content policy

  • 100% original content authored by the account operator.
  • Educational financial commentary only — never positioned as personalized investment advice.
  • Every video includes the disclaimer: "Contenido educativo. No constituye recomendación de inversión."
  • No third-party copyrighted material is republished without license.
  • Publishing is performed only on behalf of the single account that authorized OAuth — no cross-account posting.

Data handling

  • OAuth access_token and refresh_token are stored only on the operator's local machine — never transmitted to third parties.
  • No TikTok user data other than the operator's own open_id and display_name is read or stored.
  • No data from other TikTok users is collected, processed, or shared.
  • The operator can revoke API access at any time via TikTok's app management settings.
